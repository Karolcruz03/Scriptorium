# 📜 Scriptorium — Archival Paleography & HTR Workbench

**Scriptorium** is an advanced, AI-powered paleography and Handwritten Text Recognition (HTR) workbench. Built to assist historians, researchers, and archivists, it decodes complex historical manuscripts, cursive scripts, fading ink, and archaic letterforms.

## 🌍 Supported Languages
* **Spanish** (including historical/archaic orthography)
* **Latin** (medieval and classical codices)
* **English** (historical correspondence and dispatches)

## ✨ Key Features
* **Diplomatic & Normalized Editions:** Transcribe with strict adherence to original spelling, long s (`ſ`), and archaic abbreviations, or generate clean normalized versions.
* **Advanced Image Controls:** Built-in tools for high contrast, binarization, and inverted ink filters to make faded or damaged folios readable.
* **Marginalia Handling:** Automatically detects and separates margin notes from the main body text.
* **Multi-Format Export:** Easily review, analyze, and translate historical documents on the fly.

## 🛠️ Built With
* **Google AI Studio** & **Gemini API** (Multimodal vision and transcription intelligence)
* **Node.js & Express** (Backend server infrastructure)
* **Vite** (Frontend tooling)
